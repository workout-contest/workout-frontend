# 스텝포워드 (Step Forward)

AI 기반 맞춤형 건강 관리 웹 애플리케이션 프론트엔드

## 🚀 기술 스택

- React 19
- React Router DOM
- Styled Components
- Axios

## 📦 설치

```bash
npm install
```

## 🏃 실행

```bash
npm start
```

개발 서버가 [http://localhost:3000](http://localhost:3000)에서 실행됩니다.

## 🛠️ 사용 가능한 스크립트

- `npm start` - 개발 서버 실행
- `npm run build` - 프로덕션 빌드
- `npm test` - 테스트 실행
- `npm run lint` - ESLint 검사
- `npm run lint:fix` - ESLint 자동 수정
- `npm run format` - Prettier 포맷팅
